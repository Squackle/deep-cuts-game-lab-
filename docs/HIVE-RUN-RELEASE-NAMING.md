# Hive Run Release Naming

**Permanent convention:** Every Hive Run update and release has a **single-word thematic title** related to the hive, its creatures, underground biomes, mutations, or movement. Do not use informational/descriptive phrases as release titles. Use the version number separately as metadata, e.g. version `1.0.5`, title **Instinct**.

Apply this rule to the Game Lab patch notes, player-visible version badge, public release notes, roadmap and future release announcements. Technical explanations belong in the body, not the title. Keep this convention even after future repository changes or handoffs.

Current release: **Instinct** (1.0.5).
