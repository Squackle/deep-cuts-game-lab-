All six new traits start with one level; duplicate grafts must not multiply trigger count. Existing legal additive stat graft rules remain; exclude repeat pilot trait grafts from offers until a level policy is approved. All four new spells have fixed magnitude and level 1 only, do not offer nonfunctional upgrades. Existing spell upgrades remain unchanged. Equipment acquisition is via reward/inventory, not a separate paid cast; printed MV gates offers. ## B. Life-gain and deck semantics (owner approval)
The owner already approved independent once-per-event life gain triggers and at-full-health policy for Soul/Essence Warden. Revision 30 ordinary heal misses Pridemate, and Vito amount differs between partial and full HP sources. Recommend consistent nominal positive hero life gain, actual HP capped separately; Vito uses nominal amount, Pridemate/Aerialist each get one counter, Blight-Priest loses 1 from nearest foe. Ally lifelink stays ally self-heal, no hero gain (disclosed tactical deviation). Each separate strike/source produces one event; trample damage from the same strike is a single gain transaction, never duplicate. Reject zero, invalid or terminal gains; no resurrection from simultaneous lethal; use stable FIFO event IDs or source transaction boundaries and serialized pending state. Preserve earlier revision byte-for-byte. The test-only life-gain-v2-prototype exercises nominal/restored values, ordered exactly-once Pridemate consumption and terminal guards; integration with actual healing/Vito/lifelink and all event sources still needs versioned implementation and regression fixtures. No active engine import.
For draws: retain deterministic graveyard shuffle only when library empty; exile and attached cards never refill. Proposed draw one at a time, refill when empty between individual draws, stop when neither library nor graveyard contains cards; same card can return only via actual reshuffle. New draw effects use that policy; changing existing effects' batch-refill behavior requires explicit same revision approval. Opt resolves Scry on actual library, refill before reveal if empty; if no cards explain no draw; if one card both choices draw same card; keep or bottom recorded as stable action. The casting Opt is not available for its own draw unless existing authoritative cast-zone timing explicitly permits it; recommend hold casting card outside recyclable graveyard until Scry+draw resolves, then put into graveyard. Spell/ability costs validate fully before mutation; no phantom gains/draws.
