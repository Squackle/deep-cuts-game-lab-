# living-card/ — compatibility redirect only

The game formerly called *The Living Card* is now **GRAFTBOUND** and lives in `graftbound/` (route `/graftbound/`).
This folder contains only `index.html`, which redirects `/living-card/` (with query string and hash) to `/graftbound/`.
Do not add game files here. Saves are shared per origin (same `localStorage` keys), so players keep their progress.
